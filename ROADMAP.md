# Roadmap

## Proposed

- Overlay kit for OpenCode + OpenChamber upgrades — separate user-owned behavior from upstream source trees, with reproducible apply, verify, and rollback. This delays any direct upstream feature work until the compatibility contract is in place.

## Implemented, not deployed

- Provider usage-window guard — an opt-in Z.ai/Qoder account pause controller with OpenCode selector filtering. Deployment remains queued behind the overlay compatibility contract and requires the operator's exact connection IDs, approved management-credential environment reference, and a scheduler.
